# P2: Simulated UAT Project

Open `app/index.html` directly in a browser. The app is intentionally dependency-free and stores nothing. Run the rule tests with:

```powershell
node tests/validation.test.js
```

Read `requirements.md`, `uat/test-cases.csv`, `uat/defect-log.csv`, and `uat/summary.md` together. `simulated-tester-feedback.csv` contains three explicitly simulated role-play walkthroughs. `real-tester-feedback-template.csv` remains blank for any later feedback from genuine users.
